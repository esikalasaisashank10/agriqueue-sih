# 🌾 AgriQueue

AgriQueue is a **Smart India Hackathon 2026 prototype** developed by our team for the problem statement:

> **“Farmers often face long waiting times, lack of information regarding procurement schedules, and uncertainty about procurement status.”**

## 💡 About

AgriQueue helps farmers manage the procurement process by providing:

* 📍 Nearby procurement centre information
* 📅 Procurement schedules and slot booking
* 🎫 Digital queue/token system
* ⏱️ Queue position and estimated waiting time
* 📦 Procurement status tracking
* 💰 Payment status updates
* 📱 SMS and IVR support for farmers without smartphones

It also provides a dashboard for procurement centres to manage **slots, capacity and queues**.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Redis
* PostgreSQL

## 🎯 Objective

To reduce waiting time, improve transparency, and help farmers know **when to visit the procurement centre and what is happening with their procurement**.
